# Buka Aplikasi Langsung ke Satu Mode

Di tutorial ini kamu atur Menu PIN di aplikasi Pixture Photobooth, lalu kasih tahu aplikasi mau dibuka di mode mana. Setelah itu, setiap kali aplikasi mulai (kamu buka, crash, atau tablet restart) langsung masuk ke layar tamu mode itu dengan menu operator terkunci. Sekitar 5 menit.

## Kapan Dipakai {#when-to-use-it}

- **iPad atau tablet Android yang jadi booth seharian.** Tamu lihat booth, bukan layar Home kamu.
- **Tablet yang restart atau mati listrik di tengah event.** Dia balik ke booth tanpa kamu harus datang ke tabletnya.

## Sebelum Mulai {#before-you-start}

- Aplikasi Pixture Photobooth di HP atau tablet, sudah masuk pakai akunmu.
- Untuk Photo Booth (Event), Mingle Photo Booth dan Photographer Mode: event yang sudah pernah dijalankan di perangkat ini.
- Untuk atur atau ganti Menu PIN, kamu harus masuk sebagai pemilik akun, atau anggota tim yang boleh mengelola booth.

## Langkah 1: Atur Menu PIN {#step-1-set-a-menu-pin}

Menu PIN menjaga tamu supaya tidak masuk menu operator. Atur dulu, karena **Buka aplikasi di** butuh PIN.

1. Di aplikasi, buka **Settings > Start > Menu PIN**.
2. Ketik PIN 4 sampai 8 angka, lalu ketik lagi untuk konfirmasi.
3. Untuk ganti nanti, buka layar yang sama dan ketik PIN yang sekarang dulu. Ini butuh internet.
4. Untuk mematikan, buka layar yang sama lalu pilih matikan. **Buka aplikasi di** tidak bisa menyala tanpa PIN.

PIN-nya sama dengan Menu PIN di website, di **Dashboard > Booths > [booth kamu] > Menu PIN**. Atur di salah satu, dua-duanya pakai PIN yang sama.

## Langkah 2: Pilih Aplikasi Dibuka di Mana {#step-2-pick-where-the-app-opens}

1. Buka **Settings > Start > Open the app in**.
2. Pilih salah satu:
   - **Home**: layar Home biasa (bawaan).
   - **Photo Booth (Kiosk)**
   - **Photo Booth (Event)**
   - **Mingle Photo Booth**
   - **Photographer Mode**
3. Kalau belum ada Menu PIN, aplikasi minta kamu atur dulu.

Mulai sekarang, setiap start langsung masuk ke mode itu dengan menu terkunci. Untuk masuk menu operator, masukkan Menu PIN.

## Event, Mingle dan Photographer {#event-mingle-and-photographer}

Tiga mode ini membuka lagi **event terakhir yang dijalankan di perangkat ini**. Kalau aplikasi tidak bisa (lisensi hilang, event sudah dihapus atau selesai, atau tidak ada koneksi untuk cek), dia buka Home dan kasih satu baris alasannya.

## Kunci Tabletnya Juga {#lock-the-tablet-too}

**Open the app in** membuat aplikasi mulai di tempat yang benar. Tamu tetap bisa keluar dari aplikasi. Untuk itu, lihat [Kunci iPad dengan Single App Mode](/docs/single-app-mode) atau [Kunci Tablet Android Permanen](./android-dedicated-tablet.md).
