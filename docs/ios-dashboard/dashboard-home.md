# Dashboard Home

The Dashboard tab is your command center. It surfaces the numbers that matter most — how many sessions you've run, how much revenue you've earned, and which booths need attention.

<!-- Screenshot: Dashboard analytics overview -->

## Analytics Summary

At the top of the screen, you'll see key metrics for the selected time period:

- **Total Sessions** — number of completed photobooth sessions
- **Revenue** — total earnings across all booths
- **Average Per Session** — revenue divided by session count
- **Active Booths** — how many booths ran at least one session

Use the date range picker to switch between **Today**, **This Week**, **This Month**, or a **Custom Range**.

## Booth Health

Below the summary cards, the booth health section shows each booth's current status:

| Status | Meaning |
|--------|---------|
| **Online** | Booth is connected and ready for sessions |
| **Offline** | Booth has not reported in recently |
| **Idle** | Booth is online but hasn't had a session today |

:::caution
An "Offline" status doesn't always mean something is wrong — the booth device may simply be powered off between events. Check the last-seen timestamp for context.
:::

## Leaderboard

The leaderboard ranks your booths by session count or revenue for the selected period. This is especially useful if you operate multiple booths across different venues.

<!-- Screenshot: Booth leaderboard -->

:::tip
Tap any booth in the leaderboard to jump directly to its detail page, where you can review settings, assigned templates, and recent sessions.
:::

## Revenue Chart

A line or bar chart visualizes daily revenue trends over the selected date range. Spot patterns like weekend spikes or slow weekdays to help you plan staffing and marketing.

## Pull to Refresh

All data on this screen refreshes automatically when you navigate to the tab. You can also pull down to force a refresh if you want the latest numbers mid-session.
