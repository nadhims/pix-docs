# Welcome to Pix

Pix is a modern self-service photobooth system. Operators install a booth at a fixed location -- a mall, cafe, or public venue -- and walk-in customers use it on their own, any time. Whether you're setting up your first booth or managing locations across multiple venues, Pix gives you the tools to capture, share, and manage photos seamlessly.

## What is Pix?

Pix consists of two main applications:

- **Pix Desktop App** -- An Electron-based kiosk application that runs on macOS and Windows. It handles the photobooth experience: camera capture, photo filters, soft file generation (composites, GIFs, live photos, singles), printing, and microsite sharing.
- **Pix Dashboard** -- A web-based management dashboard for booth operators, at pixture.io. Monitor booth health, create templates, view real-time analytics, license your booth computers, and more -- from any desktop or mobile browser.
