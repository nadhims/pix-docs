# UI Editor

The **UI Editor** in Pix Design is where you design what customers see on the kiosk. A design is a **UI project**; each booth runs one project, chosen on the booth's **UI Project** tab.

## Screens

| Tab | Screen |
|---|---|
| **Start Screen** | The idle screen with the start button, live view, or showcase loop |
| **Custom Screen** | An optional page between start and payment, for instructions or a promotion |
| **Payment Screen** | Packages, QR popup, and sub-pages for voucher, coins, cards, and success |
| **Templates** | The template picker |
| **Capture** | Live view, countdown, timers, and the **Review** sub-page where customers check each photo and adjust it |
| **Filter** | The filter strip and preview |
| **Sharing** | Composite preview, QR block, print and extra-prints buttons |

Screens can be turned off. A booth without a Payment screen runs free photo sessions; a booth with one template can skip the Templates screen.

## Blocks

Each screen is a canvas of blocks: images, video backgrounds, text, buttons, timers and counters, the live view, template cards, the QR block, and payment blocks such as package cards and the voucher field. Blocks have position, size, corner radius, shadow, and a click action (start, next, retake, apply voucher, and so on).

## Editions

When creating a project, pick an **edition** that matches your setup, such as **Photobox** (permanent kiosk) or **Event Photobooth**. The edition organises starter designs; it does not limit what you can build.

## Publishing

Save publishes the design. Paired booths pick up changes on their next check-in, usually within seconds, without a restart.

## Plans

The UI Editor is a Pix Pro feature. On Starter you can open the editor and create one project, but only a licensed computer can run a custom design; a watermarked computer runs the standard design.

:::tip Preview at booth size
Design at the kiosk's real resolution (most booths are 1920x1080 landscape) and test on the actual screen; touch targets that look fine on a laptop can be small on a 24-inch display.
:::
