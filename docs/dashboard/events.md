# Events

An **event** is a temporary setup that gets its own pricing, its own kiosk design, a set of your booths for its dates, and a public album of everything captured.

## Creating an Event

1. Open **Events** and click **Create Event**.
2. Fill in the **event name**, **event date** (add a second day for a multi-day event), **start** and **end time**, and **venue**.
3. Set pricing for the event: **session price**, and optionally **double**, **group**, and **additional session** prices. Turn Pay Per Session off for a hosted event where the client pays you directly, such as a wedding.
4. Pick the **payment gateway** if this event should charge through a different gateway than your booths.
5. Pick which of your booths run it, then save. The event is live from that moment, for its dates. There's no draft to publish and no Start button.

## Booths and Devices

An event runs on booths you already have, not a temporary setup that disappears afterward. Pick them from the list when you create the event, or add more later from the event's own page. A booth already paired to a kiosk somewhere else, a permanent installation, won't show up in the picker; create a new booth for the event instead, then pair a computer to it as usual.

Each attached booth's computer needs Pix Pro or a pass. A spare pass in your pool covers any booth that doesn't have one yet, so add one from [Devices](./billing.md), or from the kiosk's operator menu on the day.

## Kiosk Design and Branding

Pin a kiosk design (a UI project) to the event so every booth shows the same screens, and set the event's logo and primary colour for the sharing pages. Templates created inside an event are private to it and do not appear in your org-wide template lists.

## The Public Album

Every event gets a public album at `pixture.io/album/<slug>` showing the photo sessions captured while the event was live. Share the link or QR with the client and their guests. Turn sharing off on the event to make the album private.

## Live From Creation

An event is live the moment you save it. Only sessions captured on its dates, plus one extra night so a party that runs past midnight still counts, are tagged to it and appear in its album and revenue. There's nothing to activate or complete: the event closes itself the day after its last date, and its booths go back to running as ordinary booths.

You can delete an event at any time, including while it's live. Its booths and their sessions stay untouched; only the event and its album go away.

:::info One pool for booths and events
There is one set of devices and passes, on the Devices page. A booth whose computer already holds Pix Pro or a pass is ready for the event as is. Add a pass for each of the others before you attach them, or afterward from the Devices page or the kiosk's own operator menu.
:::
