# Events

An **event** is a temporary setup that gets its own pricing, its own kiosk design, its own booths for the day, and a public album of everything captured.

## Creating an Event

1. Open **Events** and click **New event**.
2. Fill in the **event name**, **event date** (with an end date for multi-day events), **start** and **end time**, and **venue**.
3. Set pricing for the event: **session price**, and optionally **double**, **group**, and **additional session** prices. Turn payment off for a hosted event where the client pays you directly, such as a wedding.
4. Pick the **payment gateway** if this event should charge through a different gateway than your booths.
5. Save. The event starts as a **draft**.

## Station Booths and Licences

Add a **station** for each kiosk that will run at the event. Each station consumes one licence from your [License Pool](./billing.md) while the event is live; the licence returns to the pool when the event completes. You can also transfer a licence off a booth into an event slot.

Pair each station's computer with a 6-digit code from the station, exactly like a booth.

## Kiosk Design and Branding

Pin a kiosk design (a UI project) to the event so every station shows the same screens, and set the event's logo and primary colour for the sharing pages. Templates created inside an event are private to it and do not appear in your org-wide template lists.

## The Public Album

Every event gets a public album at `pixture.io/album/<slug>` showing the photo sessions captured while the event was live. Share the link or QR with the client and their guests. Turn sharing off on the event to make the album private.

## Going Live and Completing

Activate the event when the day starts and complete it when it ends. Only photo sessions captured between those two moments are tagged to the event and appear in its album and revenue.

:::info Pix Pro does not cover events
Event stations are licensed from your pool by Day Passes or transferred licences; a booth's Pix Pro subscription stays with that booth.
:::
