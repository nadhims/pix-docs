# Event Start Screen

When the start screen is turned on for your account, new events get a **start screen**. It is the first screen guests see on the booth, and the only one you design: every other screen uses the Pixture event design in your colours. Your own custom UI projects, set on a booth, still work as before.

## Where to Set It Up

Create the event first. When the start screen is on for your business, the create form asks which modes to offer and leaves the design for later. Then open the event page and click **Edit start screen** on the Start screen row.

Existing events keep working as they are. Only newly created events get a start screen.

## Modes

The modes are **Photo strip**, **Video**, **Slow-mo**, **Studio** and **Note booth**. Each one you turn on becomes a round button, and guests pick one every session. The event page shows the modes you picked as chips on the Start screen row, with a small preview.

**Photo strip**, **Studio** and **Note booth** need at least one template on the event.

### Pictures on the buttons

Choose **Illustration**, **Black and white** or **Simple icon**, or click a mode's picture to use your own.

## Look

### Background

A plain colour, a photo, a video, or the live camera, where guests see themselves like a mirror. **Darken** keeps the text easy to read on a busy photo or video.

### Title and second line

Each line has its own font. Pick a built-in font or upload your own (WOFF2, WOFF, TTF or OTF, up to 4 MB). Uploaded fonts are saved for your other events too.

### Logo

Place it above the title, instead of the title, at the top right or at the bottom, in any size from small to large.

### Colours

Pick a theme, or set your own **Primary**, **Secondary**, **Background** and **Mode circle** colours. Text colour is picked for you. Primary buttons can be **Gradient** or **Flat**.

### Labels

Turn the words under the buttons on or off for a picture-only look.

### Gallery

Turn the Gallery button on or off. Guests can reopen photos taken on this booth during this event, to scan or print again.

## Printing

**Auto print** and **Max prints** per session, counted in sheets, are not part of the start screen design. Set them on the event page, in the **Output** window, or on the **Printing** line under Start screen when the event page has no Output window.

## Payment and Staff

When the event takes payment, guests pay after tapping a mode, and turning payment on needs a session price. Staff can start a free staff session with the booth PIN. It is listed as a staff session and never counted as revenue.

## Booths and Versions

Booths in the event pick up your changes when you save. A booth needs Pixture Photobooth 1.2.0 or newer to show the start screen. An older booth keeps running Photo strip from the event's default UI project, exactly as before, and the event page warns you which booths are outdated. Update the app on any booth that should show the mode buttons.
