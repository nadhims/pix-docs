# Booth Management

A **booth** is one kiosk. Create one per physical location or station.

## Creating a Booth

1. Open **Booths** in the sidebar.
2. Click **Add Booth**.
3. Give it a name customers will never see but you will recognise ("Mall Kiosk 1", "Cafe Corner").

Booths are free: create as many as you like. A booth runs Pix Pro features when the computer paired to it is licensed, which you do from [Licenses](./billing.md).

## The Booth Page

Click a booth to open it. Everything about that booth lives in seven tabs:

| Tab | What you set there |
|---|---|
| **Templates** | Which templates this booth offers customers. See [Assigning Templates](./pix-design/assigning-templates.md) |
| **Filters** | Which photo filters appear on the kiosk's filter screen |
| **UI Project** | The kiosk design (screens, buttons, branding) this booth runs, made in the [UI Editor](./pix-design/ui-editor.md) |
| **Pricing** | Photo session price, packages, extra prints, print format, tax and fees, currency. See [Booth Pricing](./booth-pricing.md) |
| **Activity Log** | Who changed what on this booth, and when |
| **Device** | Pair, rename, or unlink the kiosk computer. See [Device Management](./device-management.md) |
| **Settings** | Name, currency, sharing outputs (singles, GIF, Live Photo, prints), and other booth-level options |

## Sharing Outputs

Under **Settings** you choose what each photo session produces besides the composite print: **singles**, **GIF**, and **Live Photo**, and whether **printing** is offered. Every output is delivered to the customer through the QR microsite on the sharing screen. See [Sharing](../desktop-app/session-flow/sharing.md).

## Booth Status

The Booths list and the **Health** page show whether each booth is online, when it last checked in, and the state of its camera, printer, and upload queue. See [Health](./health.md).

## Deleting a Booth

Open the booth's **Settings** tab and choose delete. Its photo sessions remain in the Gallery and Transactions. The licence is not affected: it stays on the computer, ready for the next booth you pair it to.

:::tip Name booths by place, not by plan
Licences move between computers; places do not. "Grand Mall L2" ages better than "Pro Booth 1".
:::
