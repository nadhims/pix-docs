# Open the App Straight Into a Mode

In this tutorial you will set a Menu PIN on the Pixture Photobooth app, then tell the app which mode to open in. After that, every time the app starts (you open it, it crashes, the tablet restarts) it goes straight to that mode's guest screen with the operator menu locked. Allow about 5 minutes.

## When to Use It

- **An iPad or Android tablet that runs as a booth all day.** Guests see the booth, never your Home screen.
- **A tablet that restarts or loses power mid-event.** It comes back to the booth without you walking over to it.

## Before You Start

- The Pixture Photobooth app on the phone or tablet, signed in with your account.
- For Photo Booth (Event), Mingle Photo Booth and Photographer Mode: an event you have already run on this device.
- To set or change the Menu PIN you must be signed in as the account owner, or as a team member who can manage booths.

## Step 1: Set a Menu PIN

The Menu PIN keeps guests out of the operator menu. Open it first, because **Open the app in** needs one.

1. In the app, open **Settings > Start > Menu PIN**.
2. Type a PIN of 4 to 8 digits, then type it again to confirm.
3. To change it later, open the same screen and type the current PIN first. This needs an internet connection.
4. To turn it off, open the same screen and choose to turn it off. You cannot keep **Open the app in** on without a PIN.

It is the same Menu PIN you can set on the website at **Dashboard > Booths > [your booth] > Menu PIN**. Set it in either place and both use it.

## Step 2: Pick Where the App Opens

1. Open **Settings > Start > Open the app in**.
2. Choose one:
   - **Home**: the normal Home screen (the default).
   - **Photo Booth (Kiosk)**
   - **Photo Booth (Event)**
   - **Mingle Photo Booth**
   - **Photographer Mode**
3. If you have no Menu PIN yet, the app asks you to set one first.

From now on, every start goes straight to that mode with the menu locked. To get into the operator menu, enter your Menu PIN.

## Event, Mingle and Photographer

These three reopen **the last event this phone ran**. If the app cannot do that (the licence is gone, the event was deleted or has ended, or there is no connection to check), it opens Home instead and shows a short line saying why.

## Lock the Tablet Too

**Open the app in** makes the app start in the right place. It does not stop a guest from leaving the app. For that, see [Lock an iPad with Single App Mode](/docs/single-app-mode) or [Lock an Android Tablet for Good](./android-dedicated-tablet.md).
