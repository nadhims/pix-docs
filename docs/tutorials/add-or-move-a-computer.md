# Add a Second Computer or Move Pix Pro

In this tutorial you will add a computer to your subscription so a second booth PC runs Pix Pro, pair that computer, move Pix Pro from an old computer to a new one, and use an Event Pass for a single event day. Allow about 15 minutes, plus checkout.

## When to Use It

- **A second self-service booth.** You open another mall kiosk next month. Add one computer to Pix Pro before you pair the new PC, so it starts without a watermark on day one.
- **A broken or retired booth PC.** The old laptop died, or you upgrade to a faster one. Deactivate the old computer and the new one takes its Pix Pro. Nothing is bought.
- **A busy weekend for an event rental.** You run two booths every day, but on Saturday you have four weddings. Buy two Event Passes for the extra computers instead of two more months of Pix Pro.
- **A multi-booth studio.** Ten computers or more: buy them in one checkout, the price per computer drops with the quantity.

Not needed when a booth only moves to a new venue with the same computer: its Pix Pro goes with it, and nothing changes on the **Computers** page.

## Before You Start

- Owner or billing access to the Pixture dashboard.
- The new computer with the Pixture Photobooth app installed, and a booth created for it (see [Set Up a Booth From Scratch](./set-up-a-booth.md)).
- A card, Apple Pay or PayPal for checkout; in Indonesia, QRIS, virtual account or e-wallet.

### How computers work

One Pix Pro on your subscription covers one computer. The **Computers** page counts them: **Computers** "2 of 3" means three places, two in use. A computer with a place runs Pix Pro. On a Pix Pro account, a computer without a place is **Blocked**: it stays paired and keeps its settings, but will not start a photo session until you deactivate another computer or add a computer. An event computer with no Pix Pro and no Event Pass reads **Needs a pass**. Pix Starter has no subscription: one computer is paired and everything is watermarked.

A spare place attaches itself. The next computer that connects takes it, so you never assign a computer by hand; you only **Deactivate** the one you want to free.

## Step 1: Add a computer to your subscription

1. Click **Computers** in the sidebar and check the **Computers** card.
2. Click **Add computer**. If places are still free, a popup says how many computers are available; click **Buy more**. Then pick **Pix Pro**. The **Get Pix Pro** checkout reads "One Pix Pro covers one computer. Pick monthly or yearly, and how many."

![Computers page of a Pix Pro account with the Computers card and the Add computer button marked](/img/docs/steps/tutorials-add-or-move-a-computer--licenses-devices.webp)

![Get Pix Pro checkout with the Monthly and Yearly cards, the How many computers? stepper and the Order summary](/img/docs/steps/tutorials-add-or-move-a-computer--licenses-add-devices.webp)

3. Set **How many computers?** with the stepper.

![Get Pix Pro checkout with How many computers? set to 3 and the volume discount in the Order summary](/img/docs/steps/tutorials-add-or-move-a-computer--licenses-add-devices-quantity.webp)

4. Open **Volume pricing** to see how the price per computer changes with quantity; several computers bought together cost less each. The table ends with "After this purchase your plan covers N computers (X now + Y new)."

![Volume pricing open in the Get Pix Pro checkout: price per computer for 1, 2 to 4, and 5 or more, and the line After this purchase your plan covers 4 computers](/img/docs/steps/tutorials-add-or-move-a-computer--licenses-volume-pricing.webp)

5. Pick **Monthly** ($39.99 per computer per month, cancel anytime) or **Yearly** ($299.99 per computer per year, about $25 per month, marked **Best value**), check the **Order summary** and click **Pay**. If you already pay by card, a **Confirm this charge** step shows the amount and **Add and pay**.

From Indonesia the same checkout shows rupiah prices, prepaid: **Monthly** Rp 850.000 and **Yearly** Rp 6.500.000, with a **Promo code** field (one use per account). A limited-time sale may show a lower price with the list price struck through.

## Step 2: Pair the new computer

1. Open **Booths**, click **Configure** on the new booth, open the **Computer** tab and click **Generate code**.
2. Enter the 6-digit code in the Pixture Photobooth app on the new computer within 10 minutes.
3. The computer takes the free place on its first check-in and appears in the table on the **Computers** page with **Pix Pro** in the **Plan** column.

![A booth Computer tab before pairing, with Generate code under Pairing & access](/img/docs/steps/tutorials-add-or-move-a-computer--booth-device-tab-unpaired.webp)

Buy first, then pair: when every place is taken and there are no unused Event Passes, the pairing code is refused with "All N computers are in use".

## Step 3: Move Pix Pro to another computer

You are retiring a booth PC and want its Pix Pro on the replacement. Nothing is bought; the place moves.

1. On **Computers**, find the old computer in the table, open its **Manage** menu and click **Deactivate**.
2. In **Deactivate this computer**, read the note: a place on your subscription frees up. Click **Deactivate**, or **Keep Pix Pro** to back out.

![Deactivate this computer popup with Keep Pix Pro and Deactivate](/img/docs/steps/tutorials-add-or-move-a-computer--licenses-deactivate-modal.webp)

3. Pair the new computer (Step 2). If it is already paired and Blocked, just leave the Pixture Photobooth app running: the next computer that checks in takes the place.

Two other actions free the place as well: logging the booth out (operator menu > **Logout**) and **Unlink** on the booth's **Computer** tab. Both return Pix Pro, or the free trial, to your account, and the next computer to check in takes it. A running Event Pass follows its own rule; see Step 5.

:::caution The place goes to whoever checks in first
If several Blocked computers are online, the first one to connect after you deactivate takes the freed place. Deactivate while only the intended computer is running the Pixture Photobooth app.
:::

## Step 4: Buy Event Passes for event days

An Event Pass is 24 hours of Pix Pro on one computer, starting from the moment you use it at the booth: $5 (Rp 85.000).

1. On **Computers**, click **Buy Event Passes** on the **Event Passes** card (or **Add computer** and pick **Event Pass**), choose how many and pay. The card shows how many are unused.

![Buy Event Pass checkout: Event Pass $5 one-time, How many computers? and Pay](/img/docs/steps/tutorials-add-or-move-a-computer--licenses-buy-passes.webp)

## Step 5: Use an Event Pass at the booth

1. On the day, an event computer with no Pix Pro asks "Use an Event Pass for today?" for the event that runs today.
2. Check the count: "You have 3 Event Passes."
3. Tap **Use Event Pass** (the menu PIN is asked first if one is set). If a Pix Pro on your account is still free, the same window also offers **Use Pix Pro**. **Not now** closes it without spending anything.

![The booth asking Use an Event Pass for today? with the title, the number of Event Passes left and Use Event Pass marked](/img/docs/steps/tutorials-add-or-move-a-computer--use-event-pass.webp)

On a computer that is not on an event, open the operator menu instead (tap the top-right corner twice within 3 seconds and enter the PIN if one is set) and tap **Use an Event Pass on this computer**. The button appears only while the computer has no Pix Pro. Either way, the booth must be online at that moment.

4. The operator menu badge now reads **Event Pass until** a time. The booth warns on its idle screen 60 and 15 minutes before the Event Pass ends; when it ends, a popup says "Your Event Pass has ended" and guests see "Please call the operator."

Rules that only apply to Event Passes:

- An Event Pass is used at the booth, never from the dashboard.
- A running Event Pass is never lost. If its computer is unlinked, deactivated, removed or logged out, the Event Pass is set aside with the same end time, and the next event computer that starts its booth continues it. A computer in Kiosk mode cannot pick it up, and the 24 hours keep counting while it waits.
- A computer paired while you hold unused Event Passes stays Blocked (an event computer reads **Needs a pass**) until one is used on it. Pixture never starts the first Event Pass on a newly paired computer for you, since that would start the 24 hours without asking.
- Once an event computer has had a pass, it is different: if that pass runs out mid-event, the next session start puts a spare Pix Pro on it or starts a spare Event Pass, with no confirm. See [Run an Event](./run-an-event.md).

## Step 6: On Pix Starter

Pix Starter has no subscription. The **Computers** card reads "No computers yet", one computer is paired, and every photo, print and GIF carries the Pixture watermark. A second computer is refused at the pairing code. To run more computers, start the 3-day free trial (one computer) or click **Add computer**.

![Computers page of a Pix Starter account: No computers yet, Pix Pro None, Event Passes 0 unused, and the Add computer button](/img/docs/licenses-starter.webp)

## Check It Worked

- The **Computers** card counts the new computer, and its row in the table shows **Pix Pro** with a recent **Last seen** time.
- **Booths** shows **Pix Pro** under **Plan** for that booth.
- The booth operator menu badge reads **Pix Pro**, and a test session has no watermark.

## Tips

- **Pair a replacement before the event day, not on it.** Pairing and the first check-in need the internet. Do both at home, then pack the computer.
- **Yearly pays off from about the eighth month.** $299.99 a year is about 7.5 months of $39.99. A booth you plan to keep for a year is cheaper on Yearly.
- **Event Passes for peaks, Pix Pro for the base.** A monthly Pix Pro costs the same as 8 Event Passes in dollars ($39.99 against $5) and 10 in rupiah (Rp 850.000 against Rp 85.000). A computer that works more days than that each month is cheaper on Pix Pro.
- **Before Pix Pro ends, Pixture warns you.** A subscription that will not renew warns 7 days and 1 day ahead by email and a dashboard banner, and the booth page badge shows the end date (**Pix Pro until** a date). An Event Pass or the free trial warns on the booth idle screen 60 and 15 minutes before the end. When the last place ends, the account returns to Pix Starter, watermarked.
- **A failed renewal gives you 3 days.** The email and banner come at once, the **Plan** column reads **Pix Pro, payment failed** and the booth shows a payment-failed banner. Fix the card under **Settings > Pixture billing** within 3 days, before the computer is Blocked.

## Troubleshooting

| Problem | Why | Fix |
|---|---|---|
| Pairing shows "All N computers are in use" or "Pix Starter runs on one computer" | Every place is taken and there is no unused Event Pass, or this is a second computer on Pix Starter | Deactivate a computer, add a computer or buy an Event Pass. Pix Starter runs one computer |
| The new computer is paired but Blocked, or reads **Needs a pass** | No free place, or you hold unused Event Passes and none is used on it yet | Deactivate another computer or add a computer; or **Use an Event Pass on this computer** |
| Deactivate freed a place but the new computer is still Blocked | It has not checked in yet, or another computer took the place | Make sure the Pixture Photobooth app is running and online; check the table on the **Computers** page |
| An Event Pass disappeared after Deactivate | The running Event Pass was set aside, waiting for the next event computer | Start the booth on an event computer: it continues the Event Pass with the same end time. A Kiosk-mode computer cannot pick it up |
| **Plan** reads **Pix Pro, payment failed** | The renewal charge failed | Update the card under **Settings > Pixture billing** within 3 days |
| Booth badge reads "Pix Pro ended, reconnect to check" | The computer was offline when its period ended | Reconnect it; the booth checks again |
