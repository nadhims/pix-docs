# Run an Event

In this tutorial you will create an event with the wizard, pair the computers that run it, start an Event Pass on each one on the day, set the modes, outputs, templates and start screen, share the online album with your client, and record what the client paid so you see the event's profit. The dashboard work takes about 15 minutes; the event then runs itself on its dates.

## When to Use It

- **A wedding, birthday or corporate party you rent your booth to.** The client pays you a fee, guests use the booth for free, and the client gets one album link with every photo.
- **A brand activation or a school event where guests pay.** Turn on **Pay Per Session** and guests pay per photo session, with the event's own prices and gateway.
- **Two or more booths at one venue.** Every computer paired to the event shows the same start screen, modes and templates, and every photo lands in one album.
- **A self-service booth that normally sits in a mall, booked out for a day.** Pair it to the event; it uses the event's look while the event runs and goes back to its everyday set afterwards.

Not for a booth that runs every day in one place for walk-in customers: that is a Kiosk booth with its own prices and templates. See [Set Up a Booth From Scratch](./set-up-a-booth.md).

## Before You Start

- **A license for every computer on the event**: Pix Pro, or an **Event Pass**: 24 hours of Pix Pro on one computer for $5 (Rp 85.000), starting when you use it at the booth, not when you buy it. Buy passes ahead on the **Computers** page (**Buy Event Passes**), or from the event page when you pair.
- **Templates for the event**, your own in Pix Design or one of Pixture's free template packs (when packs are available).
- **A payment gateway connected** (**Settings > Payment Gateway**) only if guests pay per photo session.
- **Pixture Photobooth 1.2.1 or newer** on each computer (1.2.2 or newer for a price per mode, 1.2.29 or newer for Photographer with a template, or for Mingle).

## Prepare

- **Count the passes.** One Event Pass covers one computer for 24 hours. Two booths at a one-day wedding need two passes; one booth at a two-day fair needs two passes (or one pass plus an extend). Buy them the day before so nobody pays from a phone at the venue.
- **Ask the client what they get.** Prints, GIFs, Live photos or the raw photos (Singles) are the event's **Output**. Agree it before the day, so the setup takes one pass.
- **Settle the fee.** Write down what the client pays you. You add it to the event afterwards (Step 9) and it shows on Finance.
- **Bring the venue's Wi-Fi details.** The Event Pass starts online, and photos upload to the album as they are taken.

## Step 1: Create the Event

1. Open **Events** and click **+ Create Event**. The wizard opens on **Details**.

   ![Events page with one ongoing event card and the + Create Event button](/img/docs/steps/tutorials-run-an-event--events-list.webp)

2. Fill in **Event Name** and **Client**. Open the **Modes** dropdown and pick one or more. They are grouped as "Guests pick" (**Photo** is on by default, plus **Video**, **360/Slow-mo**, **Studio** and **Decor**) and "Carried to guests" (**Photographer** and **Mingle**). Open the **Output** dropdown and pick what guests get: **Prints**, **GIF**, **Live photo** or **Singles** (the raw photos). Then set the **Event date**, the optional **Start Time** and **End Time**, and the **Venue**, and click **Next**.

   ![Create Event wizard, Details step with Event Name, Client, the Modes and Output dropdowns and the Event date](/img/docs/event-create-wizard.webp)

3. **Templates**: click **Configure** and tick the templates guests can choose from, or skip this and add them on the Setup tab later. **Next**.
4. **Screens**: "You set up the start screen on the event page, after you create the event." **Next**.
5. **Payment**: turn on **Pay Per Session** and enter the **Session price** if guests pay at this event, then switch on **Double session price**, **Group session price** or **Additional session price** only for the packages you sell; leave it off for a client-paid event. Pick a **Payment gateway** or keep the organization default.
6. Click **Create event**. The event page opens on the **Setup** tab with the **Pair a computer** popup already open.

## Step 2: Understand the Event Status

1. The event page opens with the name, dates, a status chip and a badge that reads **Free for guests** or **Paid sessions**. The chip says **ONGOING** from the moment you create the event; there is no Start button. If the dates are still ahead, the computers switch to the event's templates, start screen and prices on the first date.

   ![Event page with name, date, ONGOING chip, FREE FOR GUESTS badge, Link Sharing switch, overview cards and the Album, Setup and Report tabs](/img/docs/steps/tutorials-run-an-event--event-detail.webp)

2. The event ends by itself at 06:00 the morning after its last date (your organization's time), so a party past midnight keeps running. Computers paired with the event's code are never stopped by the dates: they keep the event until you archive it. While the event runs, each computer on it uses the event's templates, start screen, prices and gateway instead of its booth's own.

## Step 3: Pair the Computers

1. Open the **Setup** tab. Until every step is done, a progress bar at the top shows what is left; click a step to jump to it.

   ![Event Setup tab with the Computers card, Booth mode with its mode cards and Edit modes, and the Appearance tab with Edit appearance](/img/docs/event-setup-computers.webp)

2. In the **Computers** card, click **+ Pair a computer** (or use the popup that opened after you created the event). You get a 6-digit code, with **Copy code** and **New code**, when an Event Pass or a spare Pix Pro is available for it: an unused Event Pass, or a Pix Pro that is on no computer. If not, the popup says "Get Pix Pro or an Event Pass first": click **Add computer**, choose **Event Pass** (for an event) or **Pix Pro** (for regular use), pay, and the dashboard brings you back here with the code. **Pair later** closes the popup; a waiting row then has **Show code**.

   ![Pair a computer popup with a 6-digit code, "This computer has an Event Pass or Pix Pro.", Copy code, New code and Pair later](/img/docs/event-pair-popup.webp)

3. At the venue, open the Pixture Photobooth app. On a fresh computer, enter the code on the login screen. On a computer that is already set up, open the operator menu and tap **Pair with a code**; it does not log you out. Repeat for every computer at the event.
4. Each paired computer appears in the **Computers** card. **Needs Pix Pro or Event Pass** means it has no Event Pass or Pix Pro running yet; that is normal until the day (next step).

:::tip Bringing a computer that already runs Pix Pro
Unlink it from its everyday booth on the dashboard first. That puts its Pix Pro back in your account, the event shows a pairing code, and the computer pairs in on its own Pix Pro.
:::

## Step 4: Start the Event Pass on the Day

On the event date, each paired computer without Pix Pro shows a popup on its start screen before the first guest.

1. Read the title: **Use an Event Pass for today?** It names the event, says the pass runs 24 hours (until the same time tomorrow) and how many Event Passes your account has left.
2. Tap **Use Event Pass**. If you set a menu PIN, the booth asks for it first, so a guest can never spend a pass. The 24 hours start now. With a spare Pix Pro on your account, the popup offers **Use Pix Pro** instead or as well.

![The booth's Use an Event Pass for today? popup with the title and Use Event Pass marked](/img/docs/steps/tutorials-run-an-event--use-event-pass.webp)

With no unused pass, the popup reads **No Event Passes left**: tap **Buy Event Passes**, scan the QR with your phone and pay, then tap **Recheck**. **Not now** closes the popup, but the booth does not start sessions until it has an Event Pass or Pix Pro.

In the dashboard, the computer's row now shows **Event Pass** with a countdown.

## Step 5: Modes, Output and Start Screen

1. Under **Booth mode**, the event's modes are cards. **Edit modes** turns modes on or off; every computer on the event offers them, and each booth picks up a change on its next Start screen.
2. On the **Appearance** tab, click **Edit appearance** to design the start screen: background, text, logo, colours, the countdown and the session timer. **Save**, then **Try it full screen** to try it as a guest. See [Design an Event Start Screen](./event-start-screen.md).
3. The **Output** tab lists what guests get. **Change** opens the four options with a picture and a line each; tick the ones you want and **Save**. With **Prints** ticked, the same window sets **Auto print**, **Max prints per session** and **Show a Print button on Share**. Every computer on the event follows it.
4. On an event created before the start screen, the Setup tab shows **Booth mode**, **Output** and **Appearance** boxes instead, each with **Change**: one booth mode for the whole event, and a screen design made for it.

   ![Booth mode picker with Photo and Video groups](/img/docs/event-booth-mode-picker.webp)

5. With **Video**, the **Video** tab holds the video settings: **Countdown**, **Video length**, **Quality**, **Size**, **Display text before recording**, **Mirror captured videos**, **Keep original clip**, an **Overlay** (or an orientation when there is none) and optional **Intro video** and **Outro video**. They save as you go. See [Event Video Modes](../desktop-app/event-video-modes.md).

## Step 6: Assign Templates

1. In a photo mode, the **Template** tab reads "Assign at least 1 template. Until you do, guests at this event have nothing to pick." Click **Add templates** (or **+ Manage Templates**) to tick templates from your own Pix Design projects; the popup's **Browse template packs** button opens Pixture's free packs (when packs are available): each pack brings its print layouts, a GIF overlay and a matching booth look.

   ![Manage Templates modal on an event](/img/docs/steps/tutorials-run-an-event--event-manage-templates-modal.webp)

2. **Mirror** and **GIF template** sit next to it: mirroring the live view and the saved photo like a selfie, and the frame drawn over GIFs. The countdown before each shot (1 to 10 seconds) is set in **Edit appearance**.

:::info
An event's template set is exclusive. While the event runs, the booth offers only the templates assigned here, not its everyday set. Assign at least one before the doors open.
:::

## Step 7: Share the Album

1. **Link Sharing** is ON from the moment the event is created. Click **Copy** next to the album link and send it to the client. Guests and the client see every photo at that link as it uploads, and the booth shows the album's QR code on its share screen.
2. Use the toolbar above the tabs: **Embed** gives an iframe snippet for the client's website, **Slideshow** opens a full-screen slideshow for a venue screen (only while sharing is on; its look is set on the **Slideshow** tab), **Download all** zips every photo, and **Analytics** charts sessions and prints over the day.

   ![Embed modal for the public event album](/img/docs/steps/tutorials-run-an-event--event-embed-modal.webp)

3. Turn **Link Sharing** OFF to make the album private again. The **Album** tab lets you filter, select photos and delete any you should not keep. More in [Share an Event Album and Slideshow](./event-album-and-slideshow.md).

## Step 8: Watch the Event and Extend the Pass

1. Keep an eye on the **Computers** card: each Event Pass shows its time left. To add 24 hours from an unused pass, click **Extend 24h** on a computer's row, or on the booth open the operator menu and tap **Extend Event Pass 24h** (it shows how many passes are left).
2. If a pass runs out while guests are still coming, the next guest who starts a session does not get stuck: the booth puts a spare Pix Pro on the computer, or starts a spare Event Pass, and shows "New Event Pass started". This needs internet and an unused pass or Pix Pro on the account; without either, the booth stops starting sessions.
3. On **Transactions**, sessions captured during the event carry an event chip.
4. Open the **Report** tab for each computer's camera, printer, paper remaining, CPU temperature, memory, free storage, API latency, monitor, sessions, prints, active hours, incidents and printer unit, plus **Incidents during the event**.

   ![Event Report tab with per-booth health and incidents](/img/docs/steps/tutorials-run-an-event--event-report.webp)

## Step 9: Record the Booking Fee and Costs

The **Money** card at the top of the **Report** tab shows what the event earned.

1. Click **Add booking fee**, type what the client paid you under **Amount**, and click **Save**. The row then reads **Booking fee** with **Edit**; **Remove fee** in the same window takes it off.
2. Click **Add cost** for what the event cost you (crew, transport, paper), with a **Description**, an **Amount** and the **Month**.

![The event's Money card with the Booking fee row and Add cost marked, plus Guest sales, Total revenue, Total costs and Net profit](/img/docs/steps/tutorials-run-an-event--money-card.webp)

The card adds the **Guest sales** from paid sessions to the fee for **Total revenue**, takes away **Total costs**, and shows the **Net profit**. The fee counts on Finance in the month of the event date; an event with no date shows "Add the event date to count this fee". See [Booking Fees](../dashboard/finance.md#booking-fees).

**Edit** at the top of the event page changes the dates, prices or gateway at any time until the event ends, even while it is live. **Delete Event** in the toolbar removes it. At 06:00 the morning after the last date the event ends by itself. Older computers paired before Event mode are released then; Event mode computers keep the event until you archive it.

## Check It Worked

- Open the booth on one of the event's computers. It shows your start screen with a button for each mode, and the template screen shows only the event's templates.
- The computer's row in the **Computers** card shows **Event Pass** with a countdown (or Pix Pro).
- Finish a session. The **Sessions** card on the event page counts it, the photo appears on the **Album** tab and at the album link, and the row on **Transactions** shows the event chip.
- After the event, the **Money** card shows your booking fee and the net profit.

## Tips

- **Start the passes at the venue, not at home.** The 24 hours start when you tap **Use Event Pass**. Starting it the evening before eats the hours you need on the day.
- **A two-day event on one computer:** use one pass on day one, then **Extend 24h** when it nears its end, or let the booth start the next spare pass by itself at the next session.
- **Set a menu PIN before the day** (**Settings > Security**). Then only your staff can spend a pass or open the menu. See [Lock the Booth and Use the Operator Menu](./operator-menu.md).
- **Send the album link before the event**, so the client can put it on the invitation or a screen and guests find their photos the same night.
- **Do a test session after pairing** and delete the test photo from the **Album** tab, so the client's album starts clean.

## Troubleshooting

| Problem | Why | Fix |
|---|---|---|
| **Pair a computer** says "Get Pix Pro or an Event Pass first" | No unused Event Pass and no Pix Pro that is on no computer | Click **Add computer**, or unlink a Pix Pro computer from its booth to free its Pix Pro |
| A computer shows **Needs Pix Pro or Event Pass** | Nobody has started a pass on it yet | On the booth, tap **Use Event Pass** (or **Use Pix Pro**); or click **Use Pix Pro** on its row if a Pix Pro is free |
| The booth says the event "needs an Event Pass or Pix Pro before it can start sessions" | The account has no unused pass and no spare Pix Pro | Tap **Buy Event Passes**, pay on your phone from the QR, then tap **Recheck** |
| Guests cannot start a session in the evening | The 24-hour pass ran out and there was no spare pass, or the booth was offline | Buy a pass, then **Extend 24h** on the row or in the operator menu; check the internet |
| The booth still shows its everyday templates | The computer is not paired to the event, or the event's dates do not include today | Check the **Computers** card and the dates under **Edit** |
| The booth shows Photo strip instead of the mode buttons | It runs an older Pixture Photobooth | Update the app; the event page names the computer |
| Guests see nothing on the template screen | No template is assigned to the event | Add one on the **Setup** tab |
| The album link does not open | **Link Sharing** is OFF | Turn it on again |
| A mode change does not reach the booth | The booth picks it up on its Start screen | Finish the current session first |
| The booking fee is not on Finance | The event has no date, or its month is still ahead | Add the event date under **Edit**; the fee counts in that month |
